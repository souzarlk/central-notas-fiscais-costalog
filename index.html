RECUPERAÇÃO FISCAL

Histórico de notas

Pesquise uma NF-e antiga pela chave de acesso e recupere o documento quando a SEFAZ disponibilizá-lo.

Limites oficiais da SEFAZA consulta individual depende de o CNPJ estar vinculado à NF-e como destinatário, transportador ou terceiro autorizado. A recuperação pela distribuição é limitada a documentos recebidos nos últimos 90 dias. O sistema limita esta ferramenta a 15 consultas por hora para preservar margem em relação ao limite oficial.

Como recuperar um histórico maior

Use a importação em lote para documentos já exportados pelo sistema fiscal ou contabilidade.

A consulta por chave é pontual e não lista todas as notas por período. Para montar um histórico de meses ou anos anteriores, solicite os XMLs ao setor fiscal/contabilidade ou ao sistema emissor e importe vários arquivos de uma só vez. A busca automática por NSU continua responsável pelas novas notas disponibilizadas à Costalog.

Regras de processamento

• Até 100 notas por chamada à API.
• Até 500 itens de produto por NF-e.
• Duplicidade controlada pela chave de acesso.
• Arquivos inválidos são separados dos válidos.
• O XML original não fica armazenado no banco.

O certificado A1 fica codificado em Base64 como variável secreta do Render; senha e certificado nunca são enviados ao site.

Como a sincronização funciona

1. O GitHub Actions aciona a API uma vez por hora.
2. A API consulta a distribuição nacional da SEFAZ e continua do último NSU gravado no Neon.
3. Os documentos e notas são processados sem armazenar o XML original.
4. Resumos de NF-e podem aparecer antes do XML completo; a obtenção do XML completo exige manifestação do destinatário.
5. O sistema não realiza manifestação automaticamente.
SegurançaAs consultas e gravações de notas, produtos e fornecedores exigem autenticação administrativa. A rotina automática da SEFAZ utiliza credencial técnica própria.
